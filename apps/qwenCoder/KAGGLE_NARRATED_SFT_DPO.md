# Kaggle One-Click Continued SFT & DPO Pipeline: Manim Voiceover (`gemini-3.5-flash`)

End-to-end curriculum for converting, fine-tuning, and aligning **`Qwen/Qwen3-8B`** (or `Qwen/Qwen2.5-Coder-7B-Instruct`) to generate voiceover-synchronized Manim Community Edition animation code using **`gemini-3.5-flash`**, **Continued SFT**, and **Direct Preference Optimization (DPO)**.

---

## Pipeline Architecture

```
                                   [400 Standard Manim Trajectories]
                                                   │
                                                   ▼ (Inference.net API + gemini-3.5-flash)
                                   [400 Narrated Voiceover Trajectories]
                             (AOSSpeechService + <bookmark mark='...'/> tags)
                                                   │
                   ┌───────────────────────────────┴───────────────────────────────┐
                   ▼                                                               ▼
       [Continued SFT Dataset]                                           [DPO Preference Dataset]
(System + User Prompt -> VoiceoverScene)                             (Prompt, Chosen: VoiceoverScene,
                   │                                                  Rejected: Silent Scene)
                   ▼                                                               │
 [Stage 1: Continued QLoRA SFT]                                                    │
   Base: Qwen/Qwen3-8B                                                             │
   Init: nabin2004/AOS-qwen3-8b-adapter                                            │
                   │                                                               │
                   ▼                                                               ▼
 [Push SFT LoRA: nabin2004/AOS-qwen3-8b-narrated-adapter] ───────────► [Stage 2: Direct Preference Optimization]
                                                                        Policy: Base + Narrated SFT LoRA
                                                                        Beta: 0.1 (KL penalty)
                                                                                    │
                                                                                    ▼
                                                                [Push DPO LoRA: nabin2004/AOS-qwen3-8b-narrated-dpo]
```

## Code Pattern Example (`AOSSpeechService` + Bookmarks)

```python
from manim import *
from manim_voiceover import VoiceoverScene
from tools.aos_speech_service import AOSSpeechService

class MyNarratedScene(VoiceoverScene):
    def construct(self):
        self.set_speech_service(AOSSpeechService(voice="alba", cache_dir="voiceover_cache"))
        
        title = Title("Sigmoid Function")
        ax = Axes(x_range=[-3, 3, 1], y_range=[-1, 5, 1])
        curve = ax.plot(lambda x: 1 / (1 + np.exp(-x)), color=BLUE)
        dot = Dot(ax.c2p(0, 0.5), color=RED)

        with self.voiceover(
            text="Let's visualize the sigmoid function. <bookmark mark='AXES'/> We begin by creating coordinate axes, <bookmark mark='CURVE'/> plotting the sigmoid curve, <bookmark mark='DOT'/> and marking the origin point."
        ) as tracker:
            self.play(Write(title))
            self.wait_until_bookmark("AXES")
            self.play(Create(ax))
            self.wait_until_bookmark("CURVE")
            self.play(Create(curve))
            self.wait_until_bookmark("DOT")
            self.play(FadeIn(dot), run_time=tracker.duration)
```

## Standalone Commands (Local or Cloud)

### 1. Convert Trajectories via `gemini-3.5-flash` & Push to Hub
```bash
cd apps/sft
uv run python run_narrated_pipeline.py --model-id gemini-3.5-flash --concurrency 5
```

### 2. Build Aligned Datasets & Push DPO Dataset to Hub
```bash
cd apps/qwenCoder
uv run python prepare_narrated_datasets.py --push-dpo --dpo-repo nabin2004/manim-narrated-dpo-400
```

### 3. Run Continued SFT Only
```bash
uv run python run_narrated_sft.py \
    --base-model Qwen/Qwen3-8B \
    --init-adapter nabin2004/AOS-qwen3-8b-adapter \
    --hub-adapter-repo nabin2004/AOS-qwen3-8b-narrated-adapter \
    --push-to-hub
```

### 4. Run DPO Alignment Only
```bash
uv run python run_narrated_dpo.py \
    --base-model Qwen/Qwen3-8B \
    --sft-adapter nabin2004/AOS-qwen3-8b-narrated-adapter \
    --hub-dpo-repo nabin2004/AOS-qwen3-8b-narrated-dpo \
    --beta 0.1 \
    --push-to-hub
```
