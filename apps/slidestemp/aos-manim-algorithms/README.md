# aos-manim-algorithms

Computational algorithms and data structure visualization plugin for AOS Manim.

## Features
- **Data Structures**: `ArrayMobject` (indexed slots, swap animations), `NetworkXGraphVisualizer` (NetworkX graph integration).
- **Searching**: `BinarySearchVisualizer` (pointer halving traces).
- **Sorting**: `BubbleSortVisualizer` (comparison and swap steps).
- **Graph Algorithms**: `DijkstraVisualizer` (shortest paths, distance table updates).
- **Algorithm Validators**: `SortedInvariantValidator`, `GraphPathValidator`.
