# aos-manim-core

Core foundation package for the AOS Manim modular plugin ecosystem.

## Features
- **Theme Engine**: Centralized, semantic, and customizable color/typography tokens (`ThemeManager`, `ThemeConfig`, presets like `ModernDark`, `AcademicOxford`, `Nord`, `Solarized`, `Cyberpunk`).
- **Manifest Protocol**: Structured, machine-readable `plugin.json` schema and builder for domain capabilities.
- **Invariant Validators**: Spatial collision/boundary checkers and mathematical equivalence/tolerance validators.
- **Plugin Registry**: Discovery and querying mechanism across all installed plugins.
