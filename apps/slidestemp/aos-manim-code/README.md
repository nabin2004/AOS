# aos-manim-code

Code execution, memory layout, call stack, and recursion visualization plugin for AOS Manim.

## Features
- **Code Editor**: `CodeWindow` with window buttons, syntax line numbers, and active execution line highlights.
- **Runtime Stack**: `StackFrameMobject` and `CallStackMobject` to animate function call push/pop sequences and local variables.
- **Execution Tracers**: `trace_factorial_execution` and `trace_fibonacci_execution`.
- **Validators**: `AstSyntaxValidator` and `StackDepthValidator`.
