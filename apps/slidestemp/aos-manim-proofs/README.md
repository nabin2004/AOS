# aos-manim-proofs

Mathematical proof trees, step-by-step derivations, and logical argumentation visualization plugin for AOS Manim.

## Features
- **Proof Structure**: `ProofStep`, `ProofDocument`, `StepType` (Hypothesis, Lemma, Inference, Contradiction, QED).
- **Visual Derivations**: `DerivationChain` for formatted mathematical justifications.
- **Validators**: `ProofStructureValidator` to verify step dependencies and proof integrity.
