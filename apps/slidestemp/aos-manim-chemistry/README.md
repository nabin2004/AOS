# aos-manim-chemistry

STEM chemistry, molecular geometry, and reaction mechanism visualization plugin for AOS Manim.

## Features
- **Atomic & Molecular Nodes**: `AtomMobject` (standard CPK & theme-aware color mapping), `BondMobject` (single, double, triple bonds).
- **Molecules**: `Molecule2DMobject` (water, carbon dioxide, benzene, and custom molecular graphs).
- **Validators**: `ValenceValidator` to verify chemical bonding validity.
