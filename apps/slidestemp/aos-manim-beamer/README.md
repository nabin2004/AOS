# aos-manim-beamer

LaTeX Beamer presentation paradigm, frames, blocks, and themes for AOS Manim.

## Features
- **Beamer Blocks**: `Block` (standard), `AlertBlock` (warning/danger), `ExampleBlock` (success/green).
- **Beamer Frames**: `BeamerFrame` with frametitle banners, section navigation breadcrumbs, and footlines.
- **Layouts**: `BeamerColumns` and `BeamerColumn`.
- **Presentation Orchestrator**: `BeamerPresentation` declarative deck builder.
- **Validators**: `BeamerFrameOverflowValidator`.
