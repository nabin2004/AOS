# AOS Agent Skills

This directory contains domain-specific skills for AI agents operating in the AOS workspace.

For a full guide on skill installation, usage, and creating new skills, see [SKILLS.md](../../SKILLS.md).

## Installed Skills

1. **`manimce-best-practices/`**: Manim Community Edition animation guidelines, mobjects, LaTeX, 3D, and rules. Source: [adithya-s-k/manim_skill](https://github.com/adithya-s-k/manim_skill).
2. **`manimgl-best-practices/`**: ManimGL (3Blue1Brown OpenGL version) guidelines, interactive development, and templates. Source: [adithya-s-k/manim_skill](https://github.com/adithya-s-k/manim_skill).
3. **`manim-composer/`**: 3b1b-style pedagogical structuring and `scenes.md` planning. Source: [adithya-s-k/manim_skill](https://github.com/adithya-s-k/manim_skill).
4. **`manim-render/`**: Docker container management and FFmpeg audio/video assembly.
5. **`run-lecture-pipeline/`**: Step-by-step instructions for running the multi-agent lecture generation pipeline.
6. **`sft-trace-collection/`**: Data collection and prompt synthesis workflows for SFT/DPO training.
